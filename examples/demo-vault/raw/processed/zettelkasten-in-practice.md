# The Zettelkasten in Practice

Niklas Luhmann, a German sociologist, kept a slip-box (Zettelkasten) of roughly 90,000 index cards over his career and credited it for his enormous output of books and papers.

Three habits made it work:

1. One idea per card. Each note is small enough to be reused in many contexts.
2. Write in your own words. Copying a quote is not thinking; rephrasing it is.
3. Link every new card to existing ones. The value is not in any single note but in the paths between them.

Luhmann described the box as a conversation partner: following links surfaced connections he had not consciously planned.

Today the same practice runs in apps like Obsidian, where links are typed as `[[double brackets]]` and a graph view shows the network. Software makes linking cheap, which is both the benefit and the risk: it is easy to create links that mean nothing.
