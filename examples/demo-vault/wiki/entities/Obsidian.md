# Obsidian

## Summary
Note-taking app that stores notes as local markdown files and shows links between them as a graph.

## Key Points
- Links are written in double square brackets in plain text
- Graph view visualizes the note network

## Why It Matters
The viewer for this vault, and a modern home for [[Zettelkasten]] practice.

## Counter-arguments
- A pretty graph is not the same as useful connections.
