# Synthesis: Building a Thinking System

## Overview
These entries describe a system for turning reading into thinking: small linked notes, a tool to hold them, and protected time to use them.

## Shared Patterns
- Small units compose better than big ones (seen in [[Atomic Notes]] and [[Zettelkasten]])
- Tools help only when paired with a habit (seen in [[Obsidian]] and [[Deep Work]])

## Contradictions Found
- [[Zettelkasten]] rewards linking everything, while [[Deep Work]] warns against constant context switching - resolution: capture during focus, link during a separate review session.

## Key Insight
A note system is a focus system. [[Niklas Luhmann]]'s cards and [[Cal Newport]]'s focus blocks solve the same problem: keeping hard thinking from being lost or interrupted.

## Actionable Takeaways
- Keep a quick-capture inbox for ideas that come up mid-focus
- Process the inbox into atomic, linked notes once a day
