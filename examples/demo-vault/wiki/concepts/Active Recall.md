# Active Recall

**Date:** 2026-10-20
**Tags:** #learning
**Related:** [[Spaced Repetition]] · [[Feynman Technique]]

---

## The Idea
Retrieving an answer from memory strengthens it more than rereading or recognizing it.

## Why It Matters
Changes how to review notes: close the note and try to state the idea before rereading it.

## Counter-arguments
- Uncomfortable, so people avoid it even when it works
- Recall of isolated facts can still miss the bigger picture
