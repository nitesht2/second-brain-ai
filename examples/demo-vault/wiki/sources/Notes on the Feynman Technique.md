# Notes on the Feynman Technique

## Summary
Personal notes on a four-step learning method attributed to [[Richard Feynman]]: explain a concept simply, find the gaps, return to the source, simplify again.

## Key Points
- Stalling or reaching for jargon marks a gap in understanding
- Explaining forces [[Active Recall]]
- Counters the illusion of understanding that comes from rereading

## Counter-arguments
- Feynman never presented this as a named technique; it was packaged later by others
- Simple explanations can hide real complexity if you oversimplify
